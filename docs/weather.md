# Home-screen weather

The web and Expo home screens use the authenticated local `/api/weather` endpoint. The web Vite proxy points to localhost:8080; the mobile client uses EXPO_PUBLIC_API_URL.

Without query coordinates the server uses saved farm coordinates, then a saved village/district address. Address lookup is labeled approximate and ambiguous results require manual selection. Search `/api/weather/locations?q=...` returns selectable places. Device location is requested only on an explicit button tap. Denied permission, GPS timeouts, missing farm information and upstream failures show a message and keep location search available. Weather does not change the saved profile/farm.

The response contains current conditions, hourly estimates for today plus the next five calendar days, daily aggregates, units and location timezone. UI dates use that timezone and temperature is Celsius, precipitation millimetres and wind km/h. Daily/hourly panels expand on demand. Forecasts include temperature, apparent temperature, humidity, precipitation probability/amount, rain/showers/snow, pressure, clouds, visibility, wind/gusts/direction, UV, sunrise/sunset, sunshine/daylight and reference evapotranspiration. Hourly soil temperatures and moisture are modeled values, not sensor measurements. The outlook summarizes the next five days excluding today.

Source: https://open-meteo.com/en/docs and https://open-meteo.com/en/docs/geocoding-api. Attribution links appear in the UI. Forecast results are cached for ten minutes with at most 100 coordinate entries; upstream calls time out after twelve seconds. Location selection and search are protected by the existing authentication and request rate limits. Neither provider API keys nor user account details are sent to clients/providers; only weather coordinates/search terms are sent upstream.

Local non-commercial development uses the public Open-Meteo endpoint without a key. Commercial use requires an Open-Meteo subscription (https://open-meteo.com/en/terms). Save its API key as ConfigSecrets.ConfigKey=WEATHER_API_KEY, ConfigValue=<key>; this automatically selects customer-api.open-meteo.com for forecasts. Do not put the key in client environment variables. Native location permission text is configured with the expo-location plugin; native builds must include the new module/configuration, while Expo Go includes location support.
